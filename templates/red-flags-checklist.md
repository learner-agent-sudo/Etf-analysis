# Red-flags checklist — <TICKER>

Mark each: ✅ fine · ⚠️ caution · 🚩 concern · ❓ couldn't verify.

## Cost
- [ ] Expense ratio reasonable for the theme (thematic ≤ ~0.75%, broad ≤ ~0.50%)
- [ ] No unusual extra fees / fee waiver about to expire
- [ ] Bid/ask spread tight enough to trade without bleeding cost

## Strategy
- [ ] I can explain in one sentence how this fund makes money
- [ ] Not a daily-reset leveraged/inverse fund being held long-term
- [ ] If it uses options: I understand the upside cap / return shape
- [ ] If high yield: I checked it isn't largely return-of-capital

## Theme purity ⭐
- [ ] Top holdings genuinely match the stated theme
- [ ] No significant "filler" of unrelated large caps
- [ ] Mandate hasn't quietly drifted (e.g. "space" → "space & defense")
- [ ] The name honestly describes what I'd be buying

## Concentration
- [ ] Top-10 weight < 50% (or I accept the concentration)
- [ ] No single position > 10% (or I accept it)
- [ ] Enough holdings (≳ 30) for the diversification I expect

## Size & liquidity
- [ ] AUM > ~$50M (lower = closure risk)
- [ ] Adequate average daily volume
- [ ] Track record long enough to judge (≳ 1–2 yrs), or I accept the unknown
- [ ] Issuer isn't known for routinely shuttering funds

## Overlap & fit
- [ ] Doesn't heavily duplicate something I already own
- [ ] Fits my risk tolerance and time horizon
- [ ] Position size appropriate for a high-risk thematic bet

## Data quality
- [ ] Key numbers cross-checked against the issuer fact sheet / SEC filing
- [ ] Every figure has an as-of date and a source
- [ ] Aggregator vs. filing discrepancies resolved (or noted)
